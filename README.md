# My Personal Notes v2

Aplikasi catatan pribadi berbasis React — Submission 2 Dicoding React Fundamental.

## Fitur Utama
- Login & Register dengan autentikasi
- RESTful API (notes-api.dicoding.dev)
- Daftar catatan aktif & arsip dari API
- Tambah, hapus, arsip catatan via API
- Detail catatan dengan React Router
- Cari catatan real-time

## Fitur Opsional
- Ubah tema gelap/terang (localStorage)
- Ubah bahasa Indonesia/English (localStorage)
- Loading indicator saat fetch API

## Tech Stack
- React 19
- React Router DOM 7
- Vite
- ESLint (Dicoding config)

## Cara Menjalankan
```bash
npm install
npm run dev
```

Buka http://localhost:5173, daftar akun baru, lalu login.
