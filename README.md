# My Personal Notes

Aplikasi catatan pribadi berbasis React — Submission 1 Dicoding React Fundamental.

## Fitur
- Daftar catatan aktif & arsip
- Tambah catatan baru (maks. 50 karakter judul)
- Cari catatan berdasarkan judul
- Hapus & arsip catatan
- Detail catatan di halaman tersendiri

## Tech Stack
- React 19
- Vite
- ESLint (Dicoding config)

## Cara Menjalankan
```bash
npm install
npm run dev
```

Buka http://localhost:5173
